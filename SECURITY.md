# Security Policy

## Supported Versions

Security fixes apply to the `main` branch and the latest tagged release (`0.1.x`).

## Reporting a Vulnerability

If you discover a scanner bypass, proxy policy escape, or vulnerability in `mcp-ward`:

1. **Do not** disclose exploit details in a public GitHub issue before a fix is available.
2. Report privately via [GitHub Security Advisories](https://github.com/forgemorrow/mcp-ward/security/advisories/new) or email `2245265937@qq.com` with reproduction inputs and affected module paths.
3. Expect an initial acknowledgement within 72 hours and coordinated disclosure once patched.
